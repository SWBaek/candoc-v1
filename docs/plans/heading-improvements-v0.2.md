# 5단계 전체 목차 중심 개선 계획

기준 HEAD da9b1f9, 시작 작업트리 깨끗함. 대상은 실제 web-ui 5단계뿐이며 감사 보고서에서 해결된 범위/예외 검증은 유지한다.

1. 무관한 위치 재번호화/재확인과 체크박스 원문 불일치를 수정하고 격리 회귀로 고정한다.
2. 원본/3단계/저장 제목을 기본 목차로 투영한다. 자동 정답/완료가 아니다. 의심 이유/상위 맥락 탐색, 별도 근거 기반 누락 후보, 명시적 행 편집 모드와 구조/검수 분리를 구현한다.
3. 기존 Codex stdio app-server를 재사용해 모델/effort 조회 및 구조화된 제목 추천을 제공한다. 문서/규칙/검수 버전과 ref 검증 후 사용자 승인으로 초안에만 반영한다. 실제 모델 호출 대신 가짜 app-server로 검증한다.
4. 임시 DB/동적 포트/qa/stage5-improved-dist로 API·타입·빌드·전체 브라우저 회귀와 실제 문서 두 테마 캡처를 수행한다. 실제 사용자 DB/원본/기존 서버와 빌드는 전후 읽기 전용 비교한다.

4380/4382/4383 서버는 제어하지 않는다. 원본 JSON/PNG와 사용자 DB는 커밋하지 않는다. 단계별 로컬 커밋만 수행한다. push/배포/이력 재작성/6단계/교정 사본 생성은 범위 밖이다. 추천은 확정 오류/확률 점수가 아니다.


## 최종 구현·검증 (2026-10-07)

- 기본 화면은 현재 분류 목차 371개이며 일반 텍스트 2,493 후보 혼합을 제거했다. 전체 텍스트 2,937개는 보존한다. 보수적인 번호/주변 제목 규칙에서 실제 추가 누락 후보는 0개다. 이는 누락 없음 판정이 아니며 전체 텍스트 수동 탐색·후보 채택·보류를 제공한다. 불확실한 기존 제목은 목차에 남는다.
- 참고 이미지에 맞춰 제목·페이지·상태 중심의 조밀한 한 트리로 정리했다. 상세 판단·원문은 아래에서 펼치며 일괄 판단·에이전트 추천도 기본으로 접힌다. 기존 왼쪽 과정과 shadcn/토큰을 유지한다. 의심 필터/이전·다음 이동/검색 상위맥락과 모두 접기/펼치기를 제공한다.
- 행 편집 모드(F2/Enter/버튼)에서만 Tab/Shift+Tab을 처리한다. 부모/후손 깊이/위치를 함께 바꾸며 불가능한 조작을 즉시 거부한다. body 텍스트가 초기 상위 목차 맥락을 끊지 않도록 고쳤고 보류한 비제목을 제안 부모로 쓰지 않는다. 원본 수준/부모와 미검수 표시안을 구분한다.
- 감사의 두 결함을 고정했다. Beta 들여쓰기 저장 요청 ref는 Beta/Gamma 두 개뿐이고 독립 Annex payload/updatedAt/needsReview=true를 그대로 유지한다. confirmedRefs=[] 구조 저장 자체도 needsReview=true를 남긴다. 체크박스/다중 선택/Ctrl 활성화는 실제 prov 페이지와 PNG/bbox를 맞추며 출처 없는 항목은 이전 이미지/강조를 남기지 않는다. 기존 범위/예외 계약은 유지한다.
- 모델·지원 effort 선택, 묶음 대상/예외·before/after·근거, 위치/원문 이동, 사용자 승인 후 초안 적용·별도 저장을 기존 Codex stdio 연결로 구현했다. 문서/규칙 지문과 revision/ref를 검증하고 오래된 추천/불가능한 예외 부분트리를 거부한다. 실제 로컬 model/list 7개와 지원 effort를 확인했으나 thread/turn과 실제 모델 추론은 실행하지 않았다. 프로토콜/생성/실패/승인 경로는 합성 fixture만 사용했다.

## 한정사항

실 모델 추천 생성 성공·품질/의미 정답은 미검증이다. 카탈로그는 사용 권한 증거가 아니다. 제목 추천은 현재 순서를 보존하는 유효한 분류/계층안만 지원하며 position 재배치를 요구하는 추천은 거부한다. 입력은 비제목 본문 360자 축약 여부를 명시하고 2 MiB/설정된 시간·모델 컨텍스트/이용 한도를 넘으면 실패로 보고한다. 추천은 서버 메모리, 미저장 초안은 브라우저 메모리에만 존재한다. 구조 저장은 검수 기록이며 교정된 DoclingDocument 사본 생성/공식 스키마·HTML 검증은 수행하지 않았다.

원본 fixture는 working-project/ieee-1547/raw의 기존 로컬 입력이다. 검증은 tests/local-fixture.mjs가 가리키는 읽기 전용 입력과 합성/copied 임시 DB 및 동적 포트를 사용한다. 기존 미리보기는 새 코드로 재시작하지 않아 이전 화면을 유지한다. 근거 상세는 Git 제외 qa/stage5-improvements-REPORT.md, stage5-all-api.log, stage5-final-browser.log, stage5-final-heading-browser.log와 improvements-before/after.json에 있다.
