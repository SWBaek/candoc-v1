# 원본 영역 주석으로 반복 요소 검수

## 범위

3단계 실제 web-ui에 원본 PNG의 영역을 드래그하고 상자에 코멘트를 붙이는 경로를 추가한다. 기존 질문/페이지/직접 수정은 유지한다. 주석은 원본 페이지 번호·정규화 상자·대응 JSON refs·코멘트를 보존한다. 연결된 응답은 필요할 때 우측에 열며 기존 로컬 Codex app-server와 모델/effort 목록을 재사용한다.

PNG는 사람이 대조하는 용도로만 사용하고 Agent에는 예시 영역의 실제 bbox 및 유지 페이지의 JSON 문구/위치/분할 요소를 전달해 머리말·꼬리말·페이지 번호 분류를 제안한다. 동일 좌표 일괄 적용, 원문 문구 합치기/누락 복원, 소속 교정, 다음 검수 단계는 포함하지 않는다. 추천 대상별 원본/현재 역할과 제안·출처·예외를 확인하고 별도 명시 저장한다. 서버가 문서/규칙/검수 버전·실제 ref·유지 범위·예외를 검증한다. 추천 생성/선택은 역할 판단이나 완료가 아니다.

## 보존과 상태

주석과 추천 응답을 검수 DB에 보존한다. 코멘트 변경은 새 주석으로 남긴다. 새로고침/프로세스 재시작 후 주석·완료된 응답·일괄 판단/복원을 복구한다. 중단된 생성은 재요청 안내로 바꾼다. 이전 검수 버전의 추천은 조회 가능하나 적용하지 않는다. 예외·무관한 기록과 모든 원본 prov/charspan/orig/text/bbox/소속은 유지한다. 검수 판단 저장이며 교정 사본 생성은 수행하지 않는다.

## 검증과 운영 경계

합성 JSON·임시 DB·자체 포트·qa/role-annotations-dist만 사용한다. 실제 모델 호출 없이 가짜 app-server 프로세스/합성 응답으로 연결·모델 선택·좌표 및 분할 refs·버전/범위/예외·원자성·충돌 초안·새로고침/프로세스 재시작·복원과 브라우저 회귀를 확인한다. 두 테마 및 1512/1024/375/320 원본 화면을 확인한다. 기존 4380/4382/4383 서버와 실제 DB/static dist는 제어하지 않는다. 원본/DB/기존 static 지문을 전후 비교한다. 소스/문서/테스트만 로컬 커밋한다.
