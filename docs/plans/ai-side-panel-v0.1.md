# AI 응답 우측 패널 구현 계획

## 범위

- 페이지 위에 펼쳐진 추천 결과를 우측 AI 패널로 옮긴다. 요청과 응답은 대화 형태로, 추천 묶음은 이유·페이지 선택 버튼으로 표시한다.
- 기존 추천 API·판단 저장을 재사용한다. 추천 요청은 패널을 열고, 패널을 닫아도 서버 작업과 조회를 유지한다.
- 기존 우측 상세 패널과 AI 패널은 동시에 표시하지 않는다. 밝은/어두운 테마와 기존 토큰·공통 컴포넌트를 사용한다.
- 데스크톱은 원문 옆에서 독립 스크롤하고 좁은 화면은 별도로 펼친 패널에서 응답을 확인한다. 키보드 닫기와 포커스 복귀를 지원한다.

## 제외

- 자유 입력 대화·후속 턴·대화 DB는 이번 범위에 포함하지 않는다. 작동하지 않는 채팅 입력창은 만들지 않는다.
- Codex 프로토콜, 기존 페이지 판단과 완료 조건, 원본 JSON·이미지·실제 검수 기록은 변경하지 않는다.

## 완료 조건과 검증

- 추천 결과가 페이지 목록을 아래로 밀지 않고 AI 패널 안에 표시된다.
- 열기·닫기·상세 전환·진행 중 닫기/복구, 페이지 선택과 기존 제외 저장·취소, 새로고침을 브라우저에서 확인한다.
- 1512/1024/375/320px과 두 테마, 터치 영역·대비·키보드 접근을 확인한다.
- 타입 검사·빌드와 관련 브라우저 회귀 검사를 수행한다. API·저장 로직은 변경하지 않으므로 실제 Codex 추론은 재실행하지 않는다.

## 구현 및 확인 결과

- 우측 AI 패널, 요청·응답 표시, 그룹·전체 선택, 재추천·취소, 상세 패널 전환을 구현했다. 좁은 화면은 별도 패널과 포커스 유지·닫기·선택 후 복귀를 지원한다.
- 표시 모드는 원본 지문별 브라우저 설정으로 저장한다. 패널을 닫아도 컴포넌트와 상태 조회를 유지하고 결과는 기존 API에서 복구한다. 추천 API·SQLite 저장 로직은 변경하지 않았다.
- `npm run typecheck`, `npm run build`, `npm run test:browser` 통과. 긴 응답의 독립 스크롤 검사를 추가한 후 추천 브라우저 검사를 다시 실행해 통과했다. 브라우저 추천 결과는 테스트용 응답이며 실제 모델 생성은 재실행하지 않았다.
- 1512/1024/375/320px, 두 테마, 이유 텍스트 대비 4.5:1 이상, 터치 버튼 44px 이상, Escape·포커스 복귀·좁은 화면 Tab 순환, 진행 중 닫기·결과 복구, 상세 전환과 표시 모드 새로고침 복구를 확인했다.
- 기존 선택에 추천 페이지 추가, 일부 선택 해제, 제외 창의 사유·JSON 근거, 저장·취소·새로고침·서버 재시작 복구를 임시 DB에서 확인했다. 긴 응답 스크롤은 갤러리 스크롤 위치를 바꾸지 않았다.
- 밝은/어두운 데스크톱과 모바일 스크린샷을 확인했다. 기존 실행 서버 `http://127.0.0.1:4380`에서도 패널 열기·닫기를 확인했으며 브라우저 오류가 없었다. 실제 검수 상태 전체는 전후 동일했고 revision 47을 유지했다. 원본 SHA-256은 `bc2986e0685472527debf1c85129a17041501f8441270c0e69069732ca91ccff`로 동일했다.
- 디자인 계약을 v0.4로 갱신하고 README와 추천 계약에 표시·조작 범위를 반영했다.
