# 프로젝트 Codex 설정

사이드바 하단의 설정에서 로컬 Codex 연결·로그인·모델 목록을 확인하고 현재 프로젝트의 모델과 지원 Reasoning effort를 명시적으로 저장한다. 모델 목록 조회는 추론을 실행하지 않는다. 페이지/목차/영역 추천에 저장 설정을 공유하며 실행 중 요청의 설정은 변경하지 않는다.

설정은 검수 DB의 별도 프로젝트 설정에 저장한다. 검수 revision과 판단·원본에는 영향을 주지 않는다. 지원 모델/effort는 현재 서버에서 확인한 목록으로 검증하고 설정 버전 충돌 시 초안을 유지한다. 재시작 후 저장값은 복구하되 연결 상태는 미확인으로 시작한다. 기존 API의 미설정 기본값/명시 모델 요청은 호환성을 유지한다.

기존 토큰·Button·modal 패턴을 사용한다. 설정 창은 필요할 때만 열고 모바일 접힌 사이드바에서도 접근할 수 있다. 닫기/Escape/포커스 복귀·Tab 제한을 제공한다. 화면별 중복 모델 선택은 프로젝트 설정 링크로 통합한다.

검증: 임시 DB/별도 포트에서 모델 목록 조회(가짜 stdio 서버, 추론 없음), 지원 조합·충돌·재시작·세 추천 경로 전달, 설정 저장 전후 검수 보존, UI 저장/취소/키보드/두 테마·모바일 캡처를 확인한다. 타입·격리 빌드·API·전체 브라우저 회귀를 실행한다. 실제 DB/원본/기존 서버와 dist는 보존하고 로컬 커밋한다. 원격 push/배포·교정 사본 생성은 범위에 없다.
