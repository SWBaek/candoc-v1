# 5단계 UI 간소화 v0.1

2026-10-07. 기준 HEAD `981b62d`, 시작 작업트리 깨끗함.

요청: 실제 web-ui의 제목·문서 개요 화면에서 버튼과 설명을 줄이고 전체 목차를 먼저 보여준다. 프로토타입·다음 검수 단계·저장/API 계약은 변경하지 않는다.

변경:

- 세 보기 버튼을 `검수 보기` 선택 하나로 통합. 검색·의심 필터·이전/다음 이동을 목차 위에 배치한다.
- 접기/펼치기·전체 선택·선택 취소·직전 저장 복원·키보드 안내를 `목차 도구`에서 공개한다. Esc·바깥 클릭·도구 실행으로 닫는다.
- 계층 편집·실행취소·변경 저장을 목차 아래 한 작업줄에 배치한다. 편집 버튼은 활성 행으로 초점을 옮기고, 편집 중에만 들여쓰기/내어쓰기 버튼을 표시한다.
- 같은 동작인 초안 취소/저장 값으로 초안 복원을 `변경 취소`로 통합한다. 다중/숨겨진 선택·예외가 있을 때 범위를 표시하며 변경 시에만 전후 범위를 공개한다.
- 상세/일괄 판단/추천은 접힌 상태를 유지하고 검수 메모·완료도 접혀 시작한다. 추가 영역의 중첩 테두리를 줄이고 펼침 표시를 제공한다.
- 모바일 보기 선택의 텍스트 너비와 첫 화면의 목차 위치를 검증한다. 저장과 검수 확인, 초안과 승인, 활성 원문과 다중 선택의 기존 구분을 유지한다.

검증은 별도 `qa/stage5-simple-dist`, 임시 DB, 자체 포트와 합성 추천 runner만 사용한다. 실제 사용자 4380/4382/4383 서버/PID·DB·기존 dist, 원본 JSON/PNG는 제어하거나 수정하지 않는다. 모델 추론·원격 push·배포·교정 사본 생성은 수행하지 않는다.
