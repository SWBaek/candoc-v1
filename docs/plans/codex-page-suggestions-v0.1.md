# Codex 페이지 선별 추천 1차 구현 계획

## 범위

- Codex App Server의 stdio 연결 계약과 페이지 선별 추천 API를 문서화한다.
- 전체 원본 페이지의 JSON 텍스트와 표 셀 내용을 읽어 표지·목차·감사문·참여자 목록·발행 안내 등 대략적인 제외 후보를 추천한다.
- 추천은 메모리에만 보관한다. UI에서 추천 이유를 보고 전체 또는 일부를 선택한 뒤 기존 일괄 제외 창으로 적용한다.
- 추천 요청·진행·완료·빈 결과·오류·취소를 표시하고, 추천 조회나 선택은 페이지 판단 및 단계 완료를 바꾸지 않는다.

## 제외

- 정확한 요구사항 유무의 판정, JSON 교정, 교정본 출력, Docling 공식 검증, 이미지 분석, 추천 DB와 후속 대화 UI는 구현하지 않는다.
- 입력 JSON·PNG·검수 규칙과 실제 검수 판단을 개발 테스트에서 변경하지 않는다.

## 완료 및 검증

- 타입 검사·빌드, 기존 API 및 브라우저 회귀 검사를 통과한다.
- 가짜 App Server 프로세스로 초기화·최종 JSON·오류·취소와 입력/결과 경계를 검사한다. 실제 추천 생성과 구분한다.
- 격리된 임시 DB를 사용하는 실제 Codex 추천 요청으로 ChatGPT 인증·추천 생성·추천 전후 검수 상태와 원본 지문 보존을 확인한다.
- 브라우저에서 추천 표시·선택·일괄 제외 적용·새로고침 복구·취소·오류와 좁은 화면을 확인한다.

실제 검수 서버의 재시작이 필요하면 검수 기록을 보존하며 수행한다.

## 2026-10-06 구현 결과

- 연결·입력·출력·HTTP·UI 계약을 `docs/contracts/codex-page-suggestions-v0.1.md`에 작성하고 디자인 계약을 v0.3으로 갱신했다.
- 타입 검사·빌드, 18개 API/프로토콜 검사와 기존 및 추가 브라우저 검사를 통과했다.
- 실제 Codex 0.160.1 생성은 임시 DB에서 18.201초에 완료됐다. 1~15, 96~98, 138페이지를 후보로 반환했다. 추천 전후 원본 지문과 검수 상태가 같았다. 결과는 `web-ui/qa/codex-suggestions.json`에 기록했다. 이 후보는 자동 확정된 제외 판단이 아니다.
- 실제 검수 서버를 4380 포트에서 갱신하고 추천 버튼·API를 확인했다. 재시작 전후 revision 47, 페이지 판단(포함 122·제외 16), 사유·메모·완료·선택 상태가 유지됐다. PowerShell이 날짜 문자열의 소수 자릿수를 바꾸므로 시간값을 정규화해 비교했다.
- 검수 JSON의 보정은 수행하지 않았다. 따라서 Docling 스키마·HTML 교정 완료 검증은 이번 작업의 완료 항목에 포함하지 않는다.
