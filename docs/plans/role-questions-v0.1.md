# 3단계 질문 중심 검수

작성일: 2026-10-07

## 범위

반복 머리말·꼬리말·번호를 먼저 질문하고, 실제 문구와 주변 표/그림 위치가 뒷받침하는 캡션 분류 후보를 보조 질문으로 제공한다. 후보는 확정 오류가 아니다. 제목과 세부 캡션 연결은 이후 단계에서 검토한다.

기본 화면은 질문·짧은 근거·대표 원문 비교·적용 대상/예외와 제안 적용/현재대로 유지/보류다. 분류 양식은 직접 수정에서만 제공한다. 적용은 검수 기록 저장이며 원본 교정이 아니다. 유지 응답은 제안 거절이며 정상 검수와 구분한다. 보류에는 이유/후속 확인을 남긴다.

질문 진행과 전체 유지 요소 coverage를 분리한다. 페이지별 훑어보기에서는 원본/기록된 역할·소속과 위치를 함께 보고 명시적으로 선택 대상을 확인한다. 미확정·질문 미해결·여러 유지 페이지에 걸친 미검수 요소는 간편 정상 확인에서 제외한다. 알려진 기존 판단의 재검토는 명시적인 페이지 재확인으로 해소한다. 탐지되지 않았다는 이유로 저장/완료하지 않는다.

## 저장과 보호

질문 응답은 대상별 기록, source/rule/question 지문 및 revision으로 검증한다. 기록/페이지 범위 변경과 복원은 응답을 오래된 것으로 표시한다. 적용/일괄 확인은 기존 트랜잭션과 직전 저장 복원을 재사용하며 일부 실패는 전체 롤백한다. 범위 밖/예외/관련 없는 기록과 모든 prov를 보존한다.

실제 DB·원본·4380/4382/4383 서버 및 기존 dist는 수정하거나 제어하지 않는다. 임시 DB·별도 포트·qa/role-questions-dist에서만 테스트한다. 실제 모델 호출, 6단계 구현, 원격 push/배포는 범위 밖이다. 로컬 커밋한다.

## 검증

합성 API: 근거 제한·질문 중복 해소·응답 의미·예외/범위·오래된 응답·원자 실패·직전 복원·완료 제한·재시작.

브라우저: 기본 양식 숨김·대표 비교/원문/문맥·세 행동·수정/보류 초안 보호·페이지 확인·예외·새로고침/복원/충돌. 실제 fixture 두 테마 1512/1024/375/320px 캡처·대비·44px·overflow. 타입/별도 빌드/전체 API와 브라우저 회귀. 보호 대상 전후 비교.
