# 검수 UI 시안 v0.1

## 전체 검수 과정 사이드바

- 상태: 사용자 승인 완료 (2026-10-06).
- 승인 범위: 문서명 아래 전체 검수 단계 표시, 완료·현재·대기 상태의 구분, 단계 선택에 따른 중앙 작업 화면 전환.
- 기준 시안: `src/workflow.tsx`와 `review-workflow.html`. 이후 검수 UI는 이 구성을 기본으로 발전시킨다.

`npm run build:workflow`로 현재 규칙의 13개 단계를 반영한 단일 프로토타입을 만든다. 미리보기는 http://127.0.0.1:4317/workflow.html 이다.

문서명 아래에 전체 단계를 표시한다. 완료된 단계는 초록색 배경과 체크, 현재 선택 단계는 굵은 글씨와 강조, 대기 단계는 보통 굵기의 차분한 글씨로 표시한다. 단계 선택만으로 완료 상태를 바꾸지 않는다. 초기 완료 표시는 시연 값이며 실제 검수 완료를 뜻하지 않는다.

제목 목차와 대표 페이지 선별 화면을 연결했다. 제목과 페이지 번호는 원본 JSON에서 읽으며, 트리의 접기·펼치기 관계는 절 번호를 기준으로 한 시안용 구성이다. 저장된 제목 수준은 오류 검토와 깊이 조정의 대상으로 표시한다. 그 밖의 단계는 작업 안내를 표시한다.

‘시안에 저장’은 브라우저 세션 또는 대화의 시안 상태에만 기록한다. 원본 JSON과 실제 검수 기록, SQLite는 변경하지 않는다.

## 기존 세 가지 배치 시안

shadcn/ui의 공식 Button, Badge, Tabs, Textarea 컴포넌트로 구성한 세 가지 배치 시안이다.

- **3단 작업대:** 의심 목록·페이지 요소, 원문·내용·JSON, 근거·판정을 동시에 확인한다.
- **원문 중심:** 원문을 넓게 배치하고 관련 요소와 판정을 오른쪽에 둔다.
- **단계별 집중:** 한 항목의 원문과 근거를 비교하고 아래에서 판정을 입력한다.

18·19·33페이지의 미리보기와 INS-004·INS-009·INS-007을 사용한다. 좌표는 JSON의 페이지 크기와 BOTTOMLEFT 원점을 기준으로 변환한다. 이미지는 시안 용량을 줄이기 위한 축소본이며 원본 PNG는 수정하지 않는다.

원본 JSON, 기존 검수 기록, 규칙을 수정하지 않는다. 판정 입력은 시안 상태에만 저장되며 SQLite와 Codex App Server는 연결하지 않았다. 샘플 검토 개수는 전체 문서의 검수 진행률이 아니다.

```powershell
npm install
npm run prepare:fixtures
npm run build
npm run preview
```
